Режим моделирования — это режим редактора, в котором есть инструменты для создания и редактирования собственных 3D-сеток прямо в Unreal Engine. Хотя режим моделирования работает по тому же принципу, что и другие программы для моделирования, есть несколько ключевых отличий в том, как редактор создает новые сетки и обрабатывает редактирование. О них следует знать, прежде чем приступать к работе.

Тип вывода

Вы можете создать новую сетку с помощью инструментов из категорий Фигуры или Создать на палитре «Инструменты моделирования»:

Unreal Engine использует тип вывода, указанный на панели моделирования, при создании новой сетки. Типы вывода, которые не поддерживаются выбранным инструментом, отображаются серым цветом.

Статическая сетка

Статическая сетка — это тип актера, представляющий собой трехмерную геометрию. При выборе типа «Статическая сетка» актер сохраняется в браузере контента как актив, а экземпляр актера помещается на уровень.
