Neural Network Engine

Сборник материалов, посвященных использованию искусственного интеллекта в движке нейронных сетей Unreal Engine.

Узнайте, как использовать эту функцию бета-версию, но будьте осторожны при ее применении.

Neural Network Engine (NNE) предоставляет общий API для доступа к различным средам выполнения нейронных сетей и оценки нейронных сетей без необходимости писать код для конкретной среды выполнения. NNE можно использовать по-разному: для логического вывода в реальном времени, чтобы дополнить игру искусственным интеллектом (ИИ), а также для реализации функций на основе редакторов, таких как операции с ресурсами, запросы и инструменты для художников.
