Зачем нужны полигруппы и что они из себя представляют

Зачем

В традиционных программах для моделирования есть возможность использовать полигональное моделирование. Однако Unreal Engine отображает все модели в виде триангулированных сеток.

Преобразование в треугольники означает, что Unreal Engine изначально не распознает четырехугольники и многоугольники, поэтому треугольники являются основой для моделирования в движке. Чтобы приблизиться к традиционному процессу моделирования, можно использовать PolyGroups.

Что

PolyGroups — это набор сгруппированных треугольников. Группы можно использовать для:

  • UV-развертка

  • Организация материала

  • Моделирование и деформация

  • Традиционное моделирование с помощью четырехугольников

  • Создание и редактирование весов кожи

Например, используя куб импортированный из Maya, мы назначаем каждому треугольнику отдельную PolyGroup с помощью инструмента Tri Select в категории Mesh.

Чтобы визуализировать полигруппы на сетке, установите для параметра Режим отображения цвета граней значение По группам.

После настройки полигрупп вы можете использовать инструмент Редактирование полигрупп в категории Модель. Однако каждая из текущих полигрупп представляет собой отдельный треугольник, что не совсем подходит для использования инструмента «Редактирование полигрупп».

Если объединить два треугольника в одну PolyGroup, получится четырехугольник.

В этом видео с помощью Merge создается новая PolyGroup, состоящая из двух треугольников. При работе с низкополигональными сетками и блочными моделями PolyGroups позволяют взаимодействовать с более интуитивно понятными поверхностями, чем с отдельными треугольниками. Однако PolyGroups можно применять и к высокополигональным сеткам, чтобы упростить работу со сложными геометрическими объектами, которые в противном случае было бы сложно редактировать.

Анатомия PolyGroup

PolyGroup состоит из трех элементов, которые можно выбирать и редактировать:

  • Лицо: область PolyGroup.

  • Вершина: точка соединения ребер. Также называется углом.

  • Ребро: граница между PolyGroup.

При группировке треугольников для создания PolyGroup вокруг них образуется граничное ребро. В зависимости от топологии вашей сетки и сгенерированных PolyGroup редактирование ребер сетки может работать не так, как вы ожидаете, по сравнению с другими программами для создания цифрового контента (Digital Content Creation, DCC). На изображении ниже сетка состоит из двух полигрупп, представленных выделенным ребром границы. Несмотря на то, что из-за изогнутой формы граница полигрупп выглядит как несколько ребер, она не состоит из вершин полигрупп, а включает в себя только одно ребро полигруппы.

Ребра и вершины PolyGroup генерируются при соблюдении следующих условий:

  • Две или более соединяющиеся грани PolyGroup (или граница сетки) образуют ребро PolyGroup.

  • Три или более соединяющихся ребра PolyGroup образуют вершину PolyGroup.

Создание полигрупп

Чтобы лучше разобраться в полигруппах, нужно знать, какие инструменты можно использовать для их создания. Порядок использования этих инструментов зависит от вашего рабочего процесса и потребностей. Важно помнить, что в качестве полигруппы можно использовать любой набор треугольников.

Инструмент выбора треугольников

Как показано на видео выше, с помощью инструмента Tri Select можно назначить полигруппу одному или нескольким треугольникам. Вместо того чтобы выделять по одному треугольнику в PolyGroup, мы теперь выделяем по два, чтобы выполнять редактирование четырехугольников с помощью инструмента PolyGroup Edit.

На видео при пересечении каждой краевой петли создаются новые полигруппы.

Треугольники, которым не назначена PolyGroup, автоматически объединяются в одну группу.

Объединить

При использовании инструмента Редактирование полигрупп вы можете продолжить объединять существующие полигруппы в новую.

Процесс объединения существующих полигрупп является разрушительным, то есть прежние полигруппы перестанут существовать.

В видео каждое лицо представляет собой полигруппу, и вы можете объединять лица с помощью функции «Объединить».

Инструмент «Рисование полигрупп»

Существуют специальные инструменты для создания полигрупп, в том числе инструмент Рисование полигрупп, с помощью которого можно интерактивно рисовать группы.

В видео инструмент Paint PolyGroup создает новые полигруппы, состоящие из двух треугольников. Показать каркас включено для визуализации двух треугольников в каждой полигруппе.

С помощью параметра Действие можно выбрать любой из следующих режимов выделения:

  • Кисть

  • Заливка

  • Заливка группы

  • Лассо

Чтобы узнать, какая PolyGroup назначена, наведите курсор на указанную PolyGroup и нажмите горячую клавишу Shit + G. В строке Set Group отобразится соответствующее число.

Инструмент «Создать полигруппы»

Еще один специализированный инструмент для группировки треугольников — Создать полигруппы. Полигруппы автоматически назначаются при открытии инструмента. Способ назначения полигрупп определяется режимом преобразования.

С помощью выводного слоя можно создать новый слой PolyGroup.

Предустановленные фигуры

При создании предустановленных фигур в категории Создать вы можете настроить PolyGroups для новых сеток с помощью параметра Режим PolyGroup.

В режиме Polygroup доступны следующие варианты группировки:

Слои PolyGroup

Поскольку PolyGroups могут быть произвольными, вы можете создать несколько слоев PolyGroup для работы с разными наборами на одной и той же модели. Эти слои можно настроить с помощью инструмента Редактировать атрибуты в категории Атрибуты.

Слои PolyGroup не являются универсальными для вашего проекта. Вместо этого вы создаете их для отдельных статических объектов. Это означает, что нельзя предполагать, что у двух разных объектов будут одинаковые слои PolyGroup. Однако это также означает, что вы можете определять их по мере необходимости в каждом конкретном случае.

Использование полигрупп

Создание фигур

Основное назначение полигрупп — редактирование геометрии, как показано с помощью инструмента Редактирование полигрупп.

Полигруппы также помогают при создании сетки:

  • Точные региональные изменения.

    • Четыре полигруппы объединены в одну для выдавливания.

  • Создание отверстия.

  • Сглаживание сетки с помощью инструмента Subdivide.

  • Создание деформаций с помощью инструмента Deform PolyGroups.

    • Внутренние вершины PolyGroup не выделяются, только граничные. Чтобы выделить внутренние вершины, используйте Decompose для деконструкции PolyGroup.

Создание UV-разверток

Для создания UV-разверток модели можно использовать PolyGroups. В руководстве Быстрый старт в режиме моделирования к ящику назначаются шесть PolyGroups (по одной на каждую сторону). Затем на основе существующих PolyGroups создаются UV-островки.

Затем вы можете использовать инструменты UV-развертки для дальнейшего разделения UV-развертки или добавить новые полигруппы.

Теперь при развертывании модели создается больше UV-островков.

Чтобы узнать больше об инструментах UV-развертки, обратитесь к документации по категории UV-развертки.

Назначение нескольких материалов для одной сетки

Вы можете назначить несколько материалов для своей геометрии с помощью инструмента Редактировать материалы. Чтобы наглядно увидеть, каким треугольникам нужно назначить материал, вы можете выбрать полигруппы в режиме цвета граней, что особенно удобно при работе с сетками высокой плотности.

Часто задаваемые вопросы

Можно ли очистить все полигруппы, чтобы начать заново? Да, для этого нужно воспользоваться опцией Очистить все в инструменте Рисование полигрупп. Имеет ли значение, если у меня есть полигруппы, состоящие из одного треугольника? Несмотря на то, что вы по-прежнему можете редактировать сетку с помощью таких инструментов, как PolyGroup Edit, это может привести к неожиданным результатам. Например, при добавлении реберной петли к сетке, в которой верхняя сторона состоит из двух полигрупп, содержащих по одному треугольнику, петля будет наклонена в сторону. Если два треугольника объединены в одну полигруппу (представляющую собой четырехугольник), то петля будет проходить ровно.

Влияет ли создание PolyGroups на рендеринг? Нет, PolyGroups — это всего лишь инструмент, который помогает выполнять классические методы моделирования, к которым вы, возможно, привыкли в других программах для моделирования. При рендеринге по-прежнему используются треугольники.
