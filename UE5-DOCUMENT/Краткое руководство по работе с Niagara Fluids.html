Краткое руководство по работе с Niagara Fluids

Краткое руководство по использованию плагина Niagara Fluids для моделирования жидкостей в реальном времени.

Предварительные задачи:

  • Создайте новый проект

  • Включите плагин Niagara

Niagara Fluids — это плагин, который можно включить, чтобы добавить в проект шаблоны для моделирования жидкостей в реальном времени.

Цели

Из этого руководства вы узнаете, как включить плагин Niagara Fluids и создать свой первый проект.

Задачи

  • Включите плагин Niagara Fluids

  • Создайте новую систему Niagara на основе шаблона Fluids

  • Измените параметры, чтобы добиться нового внешнего вида

1. Включите плагин Niagara Fluids

Чтобы начать работу, сначала включите плагин Niagara Fluids.

  1. Нажмите на Правка > Плагины.

  2. Найдите Ниагару в строке поиска. Установите флажок слева от Ниагарского водопада.

  3. Отображается предупреждающее сообщение, поскольку этот плагин все еще находится в стадии бета-тестирования. Нажмите Да, чтобы включить плагин.

  4. Вам будет предложено перезапустить Unreal Engine. Нажмите Перезапустить сейчас.

    5. Шаблоны жидкостей теперь будут доступны вам при создании новой системы Niagara.

2. Создание системы Niagara

Далее вы создадите новую систему Niagara на основе шаблона жидкостей.

  1. Щелкните правой кнопкой мыши в панели содержимого. В разделе "Создать базовый ресурс" выберите "Система Niagara".

  2. Выберите Niagara Fluids > 3D Gas в меню слева, затем выберите Grid3D_Gas_Explosion и нажмите Создать.

  3. Переименуйте систему «Ниагара» в Grid3DGasExplosion.

  4. Перетащите систему «Ниагара» на свой уровень. Взрыв произойдет в тот момент, когда вы ее отпустите.

3. Добавьте объект для столкновения

Первое место, где можно настроить объект, — это сам уровень. В этом примере используется простая сфера.

  1. Выберите на уровне систему Ниагара.

  2. На панели Подробности в разделе Параметры переопределения при необходимости измените любой из доступных параметров. Поскольку эта система не циклическая, включайте и выключайте Показать наложения, чтобы взрыв запускался заново. Это хороший способ протестировать изменения параметров.

  3. Установите WorldSpaceSize на 300, 300, 600.

  4. Чтобы показать, как взрыв взаимодействует с объектом, добавьте в сцену простую сферу и расположите ее над взрывом. Нажмите кнопку Быстрое добавление содержимого, затем выберите Формы > Сфера.

  5. Переместите сферу так, чтобы она находилась над взрывом, но в пределах ограничительной рамки.

  6. Чтобы уменьшить пикселизацию симуляции, нужно увеличить разрешение. Выберите симуляцию, затем на панели «Сведения» в разделе «Параметры переопределения» измените ResolutionMaxAxis на 300.

  7. Затем нужно добавить к сфере тег, чтобы указать на уровне, что это объект-коллайдер.

    • Нажмите на сферу, чтобы выбрать ее.

    • На панели Сведений найдите "тег".

    • В разделе Актер, в Дополнительно > Теги, нажмите плюс (+), чтобы добавить новый тег.

    • Введите "collider" в качестве названия тега. Теперь взрыв столкнется со сферой.

4. Настройте внешний вид взрыва

Далее вы настроите внешний вид взрыва.

  1. Дважды щелкните по системе Niagara в панели содержимого, чтобы открыть ее в редакторе Niagara.

  2. Вы должны увидеть взрыв на панели Предварительный просмотр. В Обзоре системы установлены два излучателя. Если вы не видите их сразу, нажмите F, чтобы они поместились в окне.

  3. Эмиттер слева, ParticleSourceEmitter, добавляет значения в симуляцию. Эмиттер справа, Grid3D_Gas_CONTROLS_Emitter, называется эмиттером управления. Это основной эмиттер, с помощью которого вы будете настраивать внешний вид. Нажмите Сводка по эмиттеру, чтобы просмотреть доступные для настройки параметры.

    4. Нажмите и удерживайте клавишу Shift, а затем щелкните по треугольнику слева от заголовка раздела, чтобы свернуть все разделы.

  4. Сначала настройте значения затухания. Затухание определяет, насколько быстро данные будут исчезать со временем. Чем больше число, тем быстрее данные сойдут на нет. Чем меньше число, тем дольше будут сохраняться значения. Установите следующие значения, чтобы взрыв был более коротким и резким.

  5. Затем отрегулируйте значения выталкивающей силы. В этой симуляции выталкивающая сила, вызванная разницей температур, заставляет модель подниматься. Выталкивающая сила, вызванная разницей в плотности, заставляет модель опускаться. Скорость можно добавить в симуляцию, изменив значения плотности и/или температуры. Если изменить направление параметра Гравитация, выталкивающая сила будет направлена в соответствии с новым направлением. Чтобы взрыв произошел быстрее, измените значение Температурной выталкивающей силы на 3,5.

  6. Чтобы завершить настройку, измените параметры в разделе Рендеринг. По умолчанию для Рендеринг-плотности установлено значение Линейная. Это означает, что значения, заданные в Рендеринг-диапазоне плотности, будут начинаться с непрозрачности 0,0 и постепенно увеличиваться до непрозрачности 1,0 при рендеринге. Вы можете изменить общую непрозрачность, добавив значение Рендеринг-коэффициент плотности. В этом примере установите значение 0,5.

    7. По умолчанию цвета переходят от черного к красному, оранжевому, а затем к белому в соответствии с кривой излучения абсолютно черного тела. Эта кривая представляет собой физически правдоподобное отображение, которое выглядит реалистично. Она основана на цвете световых волн, излучаемых горячим абсолютно черным телом при разных температурах.

  7. Измените температуру рендеринга на кривую. В этом свойстве можно указать собственные значения для цвета.

  8. Разверните Кривую температуры рендеринга, затем Кривую. Настройте цвета по своему усмотрению, чтобы добиться желаемого результата.

  9. Когда результат вас устроит, сохрани и закрой систему «Ниагара». В редакторе уровней вы увидите взрыв в своей сцене с внесенными изменениями.
