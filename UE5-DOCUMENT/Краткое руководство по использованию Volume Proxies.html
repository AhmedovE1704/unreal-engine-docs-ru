Краткое руководство по использованию Volume Proxies

Краткое руководство по использованию Volume Proxies в аудиогеймплее.

На этой странице

Узнайте, как использовать эту функцию бета-версию, но будьте осторожны при ее применении.

Вы можете использовать компоненты Volume Proxy для взаимодействия с системой регулирования громкости игрового процесса без традиционного объекта Audio Gameplay Volume. Из этого руководства вы узнаете, как создавать динамические уровни громкости с помощью обоих типов прокси: примитивного и условного.

Необходимые условия

  • Создайте новый проект по шаблону от первого лица.

  • Включите плагин громкости звука в игровом процессе на панели Плагинов, выбрав Правка > Плагины, используя строку поиска, чтобы найти плагин, а затем установив соответствующий флажок.

1 — Настройте класс Ambient Volume Sound

Создайте и настройте новый класс Sound для проекта, чтобы поддерживать регулировку громкости звука в игре.

  1. Создайте новый класс Sound.

    1. В браузере содержимого нажмите кнопку Добавить.

    2. Выберите Аудио> Классы > Класс звука.

    3. Присвойте вновь созданному ресурсу имя, например AGV_SoundClass.

  2. Дважды щелкните по классу звука, чтобы открыть редактор классов звука.

  3. На панели Сведения:

    1. Включите маршрутизацию > Применить внешние тома.

    2. Установите значение Submix > Default 2DReverb Send Amount равным 1.0, затем сохраните его.

  4. Установите класс звука по умолчанию для проекта. Это позволит применить его ко всем источникам звука без указанного переопределения класса звука.

    1. Откройте Настройки проекта, нажав Правка > Настройки проекта в верхней строке меню.

    2. Введите "Класс звука по умолчанию" в строке поиска.

    3. Щелкните раскрывающийся список рядом с Аудио > Класс звука по умолчанию и выберите свой новый класс звука.

2. Создайте Blueprint Actor с компонентом Reverb

Создайте новый Blueprint Actor с компонентом Reverb в качестве основы для компонентов Proxy, которые вы добавите на следующих этапах.

Вы можете добавить прокси-компоненты к любому Blueprint-актору. Компоненты Audio Gameplay Volume, прикрепленные к этому прокси-актору, будут работать так же, как если бы они были прикреплены к традиционному объекту Audio Gameplay Volume.

  1. Создайте новый Blueprint Actor для прокси-сервера громкости звука в игровом процессе.

    1. В браузере контента нажмите кнопку Добавить.

    2. Выберите класс Blueprint.

    3. В окне Выбор родительского класса выберите Actor.

    4. Присвойте вновь созданному ресурсу имя, например AGV_Proxy.

  2. Дважды щелкните класс Blueprint Proxy в браузере контента, чтобы открыть редактор Blueprint.

  3. Добавьте компонент Reverb.

    1. На панели Компоненты нажмите кнопку Добавить.

    2. Введите «Reverb» в строку поиска и нажмите Enter.

  4. Выберите новый компонент реверберации (по умолчанию он называется ReverbVolume).

  5. Настройте свойства компонента реверберации на панели Сведения.

    1. Установите значение Реверберация > Громкость на 1.0.

    2. Установите значение Реверберация > Время затухания на 0.0.

    3. Щелкните раскрывающийся список рядом с Reverb > Эффект реверберации. Под заголовком "Создать новый ресурс" выберите эффект реверберации.

    4. Присвойте новому эффекту реверберации имя, например AGV_Reverb, и сохраните его.

  6. Измените эффект реверберации.

    1. Дважды щелкните значок рядом с Reverb> Эффект реверберации, чтобы открыть Редактор эффектов реверберации.

    2. Установите для поздних отражений > Усиления значение 1.0, чтобы эффект было легче услышать.

    3. Сохраните эффект реверберации и закройте редактор эффектов реверберации.

3. Создайте примитивный прокси-компонент

Примитивный прокси-компонент использует примитивную статическую сетку на объекте в качестве основы для столкновений, которые запускают события входа и выхода.

3A. Добавьте компонент примитивного прокси-компонента

Добавьте базовый компонент прокси-компонента Volume, а затем установите для него тип Primitive.

  1. Добавьте компонент Volume Proxy.

    1. На панели Компоненты нажмите кнопку Добавить.

    2. Введите в строку поиска «Volume Proxy» и нажмите Enter.

    3. Назовите компонент PrimitiveProxy.

  2. Выберите компонент PrimitiveProxy.

  3. На панели "Сведения" установите для параметра "Аудио-геймплей> Прокси" значение "Примитивный прокси AGV".

3B — добавьте компонент «Статическая сетка»

Добавьте компонент «Статическая сетка» и настройте его столкновение, чтобы можно было входить в него и выходить из него.

В настоящее время примитивные прокси не поддерживают объекты с несколькими компонентами Static Mesh. При использовании такого объекта в журнале вывода появится предупреждение.

  1. Добавьте любой компонент Static Mesh.

    1. На панели Компонент нажмите кнопку Добавить.

    2. Введите в строку поиска «Static Mesh» и выберите из списка одну из базовых фигур, например «Сфера».

  2. Выберите компонент «Статическая сетка»

  3. Задайте параметры столкновения на панели Подробности.

    1. Отключите Столкновение > Генерировать события перекрытия.

    2. Установите для Столкновения > Можно ли увеличить шаг персонажа На значение Нет.

    3. Установите для Столкновение > Предустановки значение "Пользовательский".

    4. В разделе Столкновение> Предустановки столкновений> Реакции на столкновения выберите Перекрытие. При этом выбирается Перекрытие для всех типов ответов.

  4. Сохраните план.

3C — поместите прокси-актора на уровень

  1. Разместите объект-прокси, перетащив его из браузера контента на уровень.

  2. С помощью виджета трансформации разместите объект так, чтобы ваш персонаж мог входить в него и выходить из него.

3D — создание схемы уровня

Создание схемы Blueprint для управления масштабом прокси-объекта с помощью колесика мыши.

  1. Выберите прокси-актора на уровне.

  2. На панели инструментов редактора уровней нажмите кнопку Blueprint и выберите Открыть Blueprint уровня.

  3. Щелкните правой кнопкой мыши в пустом месте и создайте ссылку на прокси-актора.

  4. На узле Ссылка на актера перетащите выходной контакт и создайте узел Получить масштаб 3D-актера.

  5. На узле Получить масштаб 3D-актера перетащите контакт Возвращаемое значение и создайте узлы Добавить и Вычесть.

  6. На узлах Добавить и Вычесть введите 1,0 в поля X, Y и Z на нижних входах.

  7. На узле Ссылка на объект перетащите выходной контакт и создайте два узла Задать масштаб объекта в 3D.

  8. Подключите выход узла Добавить к одному из узлов Задать масштаб объекта в 3D.

  9. На том же узле Задать масштаб объекта в 3D перетащите контакт Исполнить ввод (>) и создайте узел Колесо мыши вверх.

  10. Подключите выход узла Вычесть к другому узлу Задать масштаб 3D-объекта.

  11. На том же узле Задать масштаб 3D-объекта перетащите вывод Исполнить ввод (>) и создайте узел Колесо мыши вниз.

3E — проверьте уровень

Нажмите кнопку Играть на панели инструментов редактора уровней, возьмите винтовку, подойдя к ней, и выстрелите, нажав левую кнопку мыши. Вы можете изменить масштаб прокси с помощью колесика мыши. Перемещайте ползунок громкости игрового аудио и наблюдайте, как это влияет на звук выстрелов из винтовки. Эффект реверберации по-прежнему применяется в прокси-объекте с динамическим изменением размера.

4. Создайте прокси-компонент для условия

Прокси-компонент для условия запускает события входа и выхода в зависимости от условия, указанного в Blueprint через интерфейс Audio Gameplay Condition.

4A. Добавьте компонент и интерфейс прокси-компонента для условия

Добавьте базовый компонент Volume Proxy и установите для него тип «Условие».

  1. Дважды щелкните класс Blueprint Proxy в браузере контента, чтобы открыть редактор Blueprint.

  2. Добавьте компонент Volume Proxy.

    1. На панели Компоненты нажмите кнопку Добавить.

    2. Введите в строку поиска «Volume Proxy» и нажмите Enter.

    3. Назовите компонент ConditionProxy.

  3. Выберите компонент ConditionProxy.

  4. На панели "Сведения" установите для параметра "Аудио-игровой процесс> Прокси" значение "AGV Condition Proxy".

4B — добавьте интерфейс Audio Gameplay Condition

Добавьте интерфейс Audio Gameplay Condition, чтобы можно было создавать условия в Blueprint. Это добавит два новых интерфейса: Выполнение условия и Позиция выполнения условия.

  1. На панели инструментов редактора чертежей нажмите Настройки класса.

  2. Щелкните раскрывающийся список Добавить для Интерфейсов > Реализованные интерфейсы.

  3. Введите "AudioGameplayCondition" в строке поиска и нажмите Enter.

4C — создание интерфейса для выполнения условия

Интерфейс Condition Met используется для настройки любого условия, результатом которого является логическое значение. С его помощью вы можете задать собственные критерии для определения того, что находится внутри или снаружи объема.

Создайте в Blueprint проверку состояния клавиши Shift для управления интерфейсом условие выполнено.

  1. На панели "Моя схема" в разделе "Интерфейсы" > "Условия аудиоигрыша" дважды щелкните интерфейс, в котором условие выполнено.

  2. На узле возврата перетащите входной вывод возвращаемого значения и создайте узел Is Shift Down.

  3. На узле Is Shift Down перетащите входной pin-код состояния ключей и создайте узел Получить модификатор состояния ключей.

4D — создание интерфейса для определения положения при выполнении условия

Интерфейс Condition Met Position похож на интерфейс Condition Met, но предоставляет доступ к позиции слушателя для использования в пользовательском условии.

Создайте в Blueprint проверку высоты слушателя для управления интерфейсом Condition Met Position.

  1. В мой план панель, под интерфейсов > аудио геймплей состоянии, дважды щелкните выполнено условие позиции интерфейса.

  2. На узле "Положение выполнено с условием" перетащите выходной вывод "Положение" и создайте узел с вектором разрыва 3f.

  3. На узле вектора разрыва 3f перетащите выходной вывод Z и создайте узел Большего размера.

  4. На Большем узле:

    1. Введите 350,0 в нижнее поле ввода.

    2. Подключите выходной контакт к узлу возврата.

  5. Сохраните план.

4E — протестируйте уровень

Нажмите кнопку Воспроизвести на панели инструментов редактора уровней и проверьте звук выстрела из винтовки. Эффект реверберации от прокси-объекта применяется при зажатой клавише Shift или при стрельбе с платформы.

5 — попробуйте сами!

Теперь, когда вы создали несколько базовых прокси-объектов для управления громкостью, попробуйте сделать что-то еще. Ниже приведены несколько идей, которые вы можете реализовать самостоятельно.

  • Вы добавили пользовательские триггеры, но вы также можете добавить пользовательские ответы с помощью узлов событий On Proxy Enter и On Proxy Exit в Blueprint. Чтобы создать такой узел, выберите целевой компонент Volume Proxy для события, щелкните правой кнопкой мыши в пустом месте на Графе событий и добавьте узел события On Proxy.

  • По умолчанию камера считается объектом, на который направлено прослушивание, и используется для определения событий входа в зону прослушивания и выхода из нее. Если вы используете камеру от третьего лица, возможно, вам нужно, чтобы объектом, на который направлено прослушивание, был персонаж игрока. Попробуйте использовать прокси-объект Condition, чтобы переопределить стандартное столкновение по громкости в проекте Шаблон от третьего лица.
