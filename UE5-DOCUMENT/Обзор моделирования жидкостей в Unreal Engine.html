Unreal Engine 5 включает в себя набор инструментов для моделирования эффектов жидкости в реальном времени.

Этот набор инструментов разработан с учетом потребностей художников и включает в себя различные симуляторы на базе графического процессора, многократно используемые модули и надежные структуры данных, которые можно применять в редакторе Niagara. Опытные пользователи могут воспользоваться широким набором доступных параметров, чтобы настроить симуляцию в соответствии со своими потребностями.

Система моделирования жидкостей предназначена для создания сложных эффектов движения жидкостей в реальном времени, которые можно использовать в играх и видеороликах. Систему также можно использовать для запекания сложных симуляций в виде флипбуков с текстурами для различных целей.

Ключевые понятия гидродинамического моделирования

Обзор

Гидродинамическое моделирование — это процесс алгоритмической генерации данных, описывающих движение жидкостей и газов. В зависимости от используемых алгоритмов данные моделирования могут быть представлены в виде сеток или частиц.

В системе гидродинамического моделирования Unreal Engine для моделирования газов используются сетки, а для моделирования жидкостей — смесь частиц и сеток.

Сетки

Моделирование газов осуществляется с помощью сетки, в которой каждая ячейка содержит данные о плотности, температуре и скорости среды в этом месте. Чем меньше размер ячеек сетки, тем выше качество моделирования, однако за это качество приходится платить увеличением вычислительных затрат.

При рендеринге симуляции дыма вы, как правило, визуализируете сетку плотности. Участки с более высокой плотностью выглядят более непрозрачными по сравнению с участками с более низкой плотностью. Аналогичным образом работает симуляция пожара, где температура определяет цвет огня в каждой ячейке сетки. При симуляции пожара более высокая температура приводит к тому, что газ поднимается быстрее из-за выталкивающей силы.

Движение жидкости

Одним из основных компонентов моделирования реалистичного движения жидкости является процесс «вычисления давления». Этот метод предполагает решение системы уравнений, которые обеспечивают правильное обтекание жидкостью объектов и реалистичное вихревое движение.

Эта симуляция представляет собой итеративный процесс, при котором чем больше итераций, тем точнее симуляция. Однако чем больше итераций, тем выше вычислительные затраты. Важно отметить, что иногда метод «решения с давлением» может влиять на силы, добавляемые в симуляцию, и ослаблять их воздействие.

Столкновение объектов

Чтобы жидкость реагировала на близлежащие объекты, необходимо сначала задать так называемые «граничные условия».

При установке граничных условий для моделирования необходимо замаскировать области, в которых находятся объекты, чтобы жидкость не могла занимать то же пространство. Эти объекты, участвующие в столкновении, могут перемещаться по сцене, и их скорость используется для перемещения жидкости вокруг них.

В качестве примера можно привести ситуацию, когда объект падает в лужу, вызывая брызги и рябь вокруг себя. Система может использовать в качестве коллайдеров множество типов объектов, таких как статические сетки, геометрические коллекции и карты глубины.

Жидкости

В Niagara Fluids для моделирования жидкостей, например текущей воды, используется гибридный алгоритм на основе частиц и сетки под названием FLIP (Fluid-Implicit-Particle). В этой системе скорость жидкости вычисляется на сетке, а затем преобразуется обратно в частицы, которые представляют форму жидкости.

Обратите внимание, что моделирование жидкостей и газов во многом схоже, поэтому предыдущие разделы, посвященные объектам столкновения и движению жидкости, применимы и к жидкостям.

Интерфейсы сеточных данных

Коллекция 2D-сеток и Коллекция 3D-сеток — это интерфейсы данных для хранения именованных атрибутов в 2D- и 3D-сетках соответственно. Они используются для всех необходимых вычислений при моделировании жидкостей.

Этапы моделирования

На каждом этапе алгоритма моделирования газов или жидкостей система моделирования жидкостей Unreal Engine проверяет, обработаны ли все ячейки сетки, прежде чем перейти к следующему этапу. Для этого система использует так называемые этапы моделирования в Niagara. Обратите внимание, что этапы моделирования можно запускать несколько раз, прежде чем переходить к следующему этапу, изменив атрибут Num Iterations этапа.

Многоразовые модули

Большая часть поведения жидкости определяется в модулях, которые можно перемещать в стеке системы Niagara. Некоторые модули используются в 2D-, 3D-, газовых и жидкостных симуляторах и, как правило, имеют универсальный характер. Опытные пользователи могут изменять основные параметры решателя для жидкостей, модифицируя или заменяя различные модули.

Типы симуляторов

2D-симулятор газа

Это симулятор газа, в котором движение происходит только в двухмерном пространстве. Такие симуляции обычно выполняются намного быстрее, чем трехмерные, и лучше всего подходят для игр и использования в режиме реального времени. Однако в них, как правило, отсутствует сложный турбулентный поток, который можно наблюдать в трехмерных симуляциях.

Важно отметить, что 3D-объекты могут взаимодействовать с 2D-моделями. Такие модели можно настроить так, чтобы они всегда были ориентированы на камеру и имитировали трехмерное поведение. Это часто используется при создании факелов или других эффектов пламени, где необходима глубина.

2D-моделирование газа выполняется на плоскостях, которые либо обращены к камере, либо ориентированы в пространстве.

3D-моделирование газа

Это наиболее распространенный тип моделирования газа. По сравнению с 2D-моделированием, 3D-моделирование позволяет имитировать глубину и более сложные потоки, но требует больше памяти и ресурсов графического процессора. Этот тип симулятора лучше всего подходит для создания эффектов героев в приложениях, работающих в режиме реального времени, а также для кинематографических эффектов. Результаты также можно использовать для создания текстур, чтобы повысить производительность в режиме реального времени. Моделирование газов с использованием запеченного освещения позволяет добиться эффекта самотени за счет запекания теней в сетку. Затем эти данные передаются в материал для рендеринга. Материалы с трассировкой лучей отвечают за создание изображений объема путем накопления данных о видимой плотности и температуре.

2D FLIP

2D FLIP отбирает 3D-частицы и создает 2D-область для моделирования, в которой рассчитывается давление и применяется алгоритм FLIP для обновления частиц. Как правило, область моделирования выровнена по камере, что позволяет создавать сложные трехмерные потоки, несмотря на использование двумерных сил, действующих на жидкость. Это можно использовать для создания реалистичных эффектов разбрызгивания, но не для моделирования водоемов. Моделирование с помощью 2D FLIP обычно выполняется с использованием 3D-частиц.

Мелководье

В отличие от 2D FLIP, модель «Мелководье» подходит для имитации водоемов, в которых не так много брызг. С ее помощью можно имитировать кильватерный след от лодки или простые взаимодействия с объектами, движущимися по воде. Моделирование мелководья — это поля высот, которые отображаются как смещения относительно поверхности воды.

3D FLIP

Моделирование с помощью 3D FLIP — это надежная симуляция жидкости, которая позволяет имитировать широкий спектр эффектов, таких как волны на пляже, реки и сложные взаимодействия объектов. Обратите внимание, что такое сложное моделирование может потребовать больших вычислительных мощностей. Это моделирование движения частиц, при котором скорости определяются с помощью сеточного решателя, который предотвращает сжатие жидкости. При 3D-моделировании методом FLIP частицы распределяются по сетке, а затем сетка визуализируется как поверхность с помощью трассировки лучей.
